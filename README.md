## Sobre el book

El book está organizado en las siguientes unidades, a las que podés acceder usando el menú de la izquierda:

| Unidad | Tema |
|---|---|
| 1 | Planilla de cálculo |
| 2 | Manipulación de datos |
| 3 | Análisis exploratorio de datos — Medidas de resumen |
| 4 | Análisis exploratorio de datos — Visualización de datos |
| 5 | Transformación de datos |
| 6 | Ajustes y modelos |
| Complemento (Unidades 2 y 3) | Métodos avanzados — Medidas de similaridad y distancia |

Para cada una de las unidades anteriores, podés encontrar tres tipos de materiales:

- 📖 **Materiales de lectura**. Desarrollo conceptual de cada tema, con ejemplos y código de Python.

- 🖥️ **Diapositivas de cada clase**. Diapositivas que se utilizan en los encuentros virtuales de presentación de contenidos, en formato HTML.

- ✏️ **Prácticas**. Ejercicios pensados para aplicar lo visto en cada unidad, que se trabajan en las clases presenciales prácticas de la asignatura.

## Datasets utilizados

Los siguientes archivos se utilizan a lo largo de los diferentes *Materiales de lectura*:

| Dataset | Unidad | Descripción |
|---|---|---|
| [`earthquakes.csv`](https://raw.githubusercontent.com/tuiafceiaunr/fdcd/main/unidades/u2-manipulacion-datos/datasets/earthquakes.csv) | 2 | Terremotos registrados por el USGS (*United States Geological Survey*), descargados directamente desde su API pública: sismos de magnitud 4.5 o mayor, ocurridos entre agosto de 2025 y agosto de 2026. El archivo fue modificado con fines pedagógicos. |
| [`hogares.xlsx`](https://raw.githubusercontent.com/tuiafceiaunr/fdcd/main/unidades/u2-manipulacion-datos/datasets/hogares.xlsx) | 2 | Dataset simulado de propiedades en la ciudad de Rosario, utilizado para ilustrar estrategias de imputación de datos faltantes. |
| [`enfr2018.txt`](https://raw.githubusercontent.com/tuiafceiaunr/fdcd/main/unidades/u3-analisis-exploratorio-datos/datasets/enfr2018.txt) | 3 | Encuesta Nacional de Factores de Riesgo 2018. La misma releva información sobre condiciones de salud, hábitos y factores de riesgo en la población adulta argentina. |
